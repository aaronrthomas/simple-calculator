# Simple Calculator with History

A minimal static calculator app built with HTML, CSS, and JavaScript.

## Features
- Basic arithmetic operations: addition, subtraction, multiplication, division
- Percent support

## Run
1. Open `index.html` in a browser.
2. Use the buttons to build expressions and press `=` to evaluate.

## Files
- `index.html` — main UI markup
- `styles.css` — app styling
- `script.js` — calculator behavior and history logic
